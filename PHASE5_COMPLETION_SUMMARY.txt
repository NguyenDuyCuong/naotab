📊 SCHEMA v5 STRUCTURE

New Fields Added (12+ total):

Publication & Source:
  • publish_date: ISO date string (extracted from pageMeta)
  • author: Author name
  • source: Publication/domain name
  • origin: Geographic or organizational origin

Content Analysis:
  • content_context: Main topic/domain (AI-generated)
  • purpose: Why content was created
  • thesis: Main argument/claim
  • evidence: Supporting data points
  • key_message: One-liner summary

Extracted Knowledge:
  • concepts: [{name, relevance (0-1), type}]
  • entities: [{name, type, value}]
  • keywords: [{word, frequency, relevance}]
  • key_statistics: [{label, value, context}]
  • events: [{date, description}]
  • differentiators: Unique selling points

Extraction Tracking:
  • ai_extracted_fields: List of extracted fields
  • extraction_confidence: Overall confidence (0-1)
  • extraction_timestamp: ISO timestamp

🔄 EXTRACTION ENGINE (core/extraction.js)

Core Functions:
  1. extractConcepts(text) - 5-7 high-level concepts with relevance
  2. extractEntities(text) - Named entities with types
  3. extractKeywords(text) - Technical keywords with frequency
  4. parseMetadata(pageMeta) - Publication metadata
  5. analyzeContentStructure(text) - Purpose, thesis, key message

Helper Functions:
  • extractPhrases() - N-gram extraction
  • isStopWord() - Common word filtering
  • detectConceptType() - Concept classification
  • detectEntityType() - Entity classification
  • calculateKeywordRelevance() - Keyword scoring

Fallback Strategy:
  • AI extraction primary (extractBookmarkMetadata in ai.js)
  • Offline extraction fallback (functions in extraction.js)
  • Never returns empty; always has valid data

🚀 FEATURE HIGHLIGHTS

1. Hybrid Extraction Model:
   • Quick extraction on save (parse, keywords)
   • Full extraction via "AI Extract All" batch button
   • Optional, not forced

2. Confidence Tracking:
   • Each extraction has confidence score (0-1)
   • Fields marked with confidence
   • Users see how reliable extracted data is

3. Layer Persistence:
   • User layer preferences saved to localStorage
   • Concept/entity layers remember show/hide state
   • Works across sessions

4. Multi-Type Graph:
   • 4 distinct node types with colors
   • Mixed edges between different types
   • Relevance filtering prevents clutter
   • Smooth transitions on layer toggle

5. User Control:
   • Extract button optional
   • "AI Extract All" for batch processing
   • Edit extracted fields manually
   • Confidence scores visible
